# Конспекты университета

Репозиторий для конспектов занятий: лекций, семинаров и практических работ. Материалы хранятся в Markdown, поэтому их удобно читать прямо на GitHub, редактировать в любом текстовом редакторе и отправлять одногруппникам ссылкой.

## Структура

Материалы группируются по учебному году, семестру и предмету:

```text
├── 1 курс/
│   ├── 1 семестр/
│   │   ├── Название предмета/
│   │   │   ├── README.md
│   │   │   ├── 2026-09-01 — Тема занятия.md
│   │   │   └── ...
│   │   └── ...
│   └── 2 семестр/
└── ...
```

Для файлов занятий удобно указывать дату и тему. Если предмету нужны дополнительные материалы, их можно хранить в папке этого предмета.

## Как вести конспект

1. Создайте папку предмета в нужном семестре.
2. Добавьте Markdown-файл с датой и темой занятия.
3. Запишите основные понятия, ход решения и примеры.
4. Сохраните изменения коммитом — так останется история правок.
5. Поделитесь ссылкой на файл или папку с одногруппниками.

## Шаблон занятия

Скопируйте этот шаблон в новый файл:

```markdown
# Тема занятия

**Дата:** ГГГГ-ММ-ДД  
**Тип занятия:** лекция / семинар / практика

## Кратко

Главная идея занятия в нескольких предложениях.

## Основные понятия

- **Термин** — определение.

## Конспект

Записи по теме.

## Примеры и задачи

Условия, решения и пояснения.

## Вопросы

- Что нужно уточнить или повторить?
```

## Формат

- Конспекты — в файлах `.md`.
- Изображения и другие файлы добавляйте в папку рядом с конспектом, если они нужны для понимания материала.
- В названиях файлов используйте формат `ГГГГ-ММ-ДД — Тема.md`.

## Совместная работа

Репозиторий можно читать по ссылке. Если у одногруппников есть доступ на запись, они могут предложить исправления и дополнения через коммиты или pull request. Для важных правок полезно указывать источник или дату занятия.
