## 1. Что означает предел последовательности

Число a называется пределом последовательности xₙ, если члены последовательности становятся сколь угодно близки к a при достаточно больших n.

Формальное определение:
~~~text
для любого ε > 0 существует N₀ = N₀(ε),
такое, что для всех n > N₀ выполняется |xₙ − a| < ε.
~~~

Обозначение:
~~~text
limₙ→∞ xₙ = a
~~~

Здесь:

- ε — произвольная положительная точность;
- N₀ — номер, начиная после которого все члены последовательности попадают в ε-окрестность числа a;
- N₀ может зависеть от ε.

Важно: последовательность может приближаться к пределу, не принимая его значение ни при каком n. Предел описывает поведение «хвоста» последовательности, поэтому изменение конечного числа первых членов на предел не влияет.

### Пример: 1/n стремится к нулю

~~~text
xₙ = 1/n
~~~

При n = 1, 2, 3, … получаем 1, 1/2, 1/3, … Чем больше знаменатель, тем ближе дробь к нулю.

Эта последовательность:

- убывает;
- ограничена: 0 < 1/n ≤ 1;
- сходится к 0.

### Сходимость не требует монотонности

~~~text
xₙ = (−1)^(n+1) / n
~~~

Знаки чередуются, поэтому последовательность не является монотонной. Но модуль члена равен 1/n и стремится к нулю. Значит, сама последовательность тоже стремится к нулю.

Члены приближаются к нулю с двух сторон. Пример показывает, что монотонность и сходимость — разные свойства: немонотонная последовательность может сходиться.

## 2. Как доказывать предел по определению

Чтобы доказать, что lim xₙ = a:

1. записать, что ε > 0 произвольно;
2. рассмотреть |xₙ − a|;
3. оценить это выражение через n;
4. подобрать N₀, зависящий от ε;
5. проверить, что при каждом n > N₀ выполняется |xₙ − a| < ε.

### Пример: 0,9; 0,99; 0,999; … стремится к 1

Если в n-м члене записано n цифр 9 после запятой, то:
~~~text
xₙ = 1 − 10^(−n)
|xₙ − 1| = 10^(−n)
~~~

Нужно подобрать N₀ так, чтобы 10^(−n) < ε при всех n > N₀. Решая неравенство относительно n, можно применить логарифм. Например, при ε = 10^(−3) достаточно взять N₀ = 4: начиная с пятого члена погрешность меньше одной тысячной. Это не обязательно наименьший возможный номер, но условие определения выполняется.

Логарифм появляется только для того, чтобы выразить n из неравенства с показательной функцией.

Если последовательность сходится к a, то в любой окрестности a содержится бесконечно много её членов; более того, все члены начиная с некоторого номера находятся в этой окрестности.

## 3. Сходящиеся, бесконечно малые и бесконечно большие последовательности

- Последовательность называется **сходящейся**, если у неё существует конечный предел.
- Последовательность называется **бесконечно малой**, если её предел равен нулю:
  ~~~text
  xₙ → 0
  ~~~
- Последовательность называется **расходящейся**, если конечного предела у неё нет.
- Последовательность называется **бесконечно большой**, если её члены по модулю становятся больше любого заранее заданного положительного числа:
  ~~~text
  для любого E > 0 существует N₀,
  что при n > N₀ выполняется |xₙ| > E
  ~~~

Для бесконечно малой последовательности в определении просто полагают a = 0. В записи лекции также поясняли, что при нулевом пределе не нужно писать «минус ноль»: это то же самое число 0.

**Важно:** не всякая ограниченная последовательность сходится. Например, последовательность может оставаться в пределах от −1 до 1 и продолжать колебаться.

## 4. Подпоследовательности

Подпоследовательность получают, выбирая члены исходной последовательности с индексами, которые строго возрастают:
~~~text
xₙₖ, где n₁ < n₂ < n₃ < …
~~~

Например, можно оставить только члены с чётными индексами, с нечётными индексами или каждый пятый член.

### Свойства подпоследовательностей

1. Если исходная последовательность сходится к a, любая её подпоследовательность тоже сходится к a.
2. Если две подпоследовательности, которые вместе охватывают все члены (например, чётная и нечётная), сходятся к одному и тому же числу a, то исходная последовательность сходится к a.
3. Если у исходной последовательности есть расходящаяся подпоследовательность, то исходная последовательность расходится.
4. Если две подпоследовательности сходятся к разным пределам, исходная последовательность расходится.
5. Из всякой ограниченной последовательности можно выделить сходящуюся подпоследовательность (теорема Больцано—Вейерштрасса).

### Пример: колеблющаяся последовательность

Рассмотрим:
~~~text
xₙ = sin(πn/2)
~~~

Её члены повторяются:
~~~text
1, 0, −1, 0, 1, 0, −1, 0, …
~~~

Подпоследовательность с индексами, кратными четырём, равна 0, а подпоследовательность с индексами вида 4k + 1 равна 1. Эти подпоследовательности сходятся к разным числам, поэтому вся последовательность расходится.

При этом она ограничена:
~~~text
−1 ≤ sin(πn/2) ≤ 1
~~~

Следовательно, ограниченность сама по себе не гарантирует сходимость.

## 5. Пример со средним арифметическим первых чисел

Во второй части лекции продолжили пример, оборвавшийся в первой записи. Рассматривается последовательность частичных сумм:
~~~text
xₙ = (1 + 2 + … + (n−1)) / n²
~~~

Например:

~~~text
x₂ = 1/2² = 1/4
x₃ = (1 + 2)/3² = 3/9 = 1/3
~~~

Сумма первых n−1 натуральных чисел равна:
~~~text
1 + 2 + … + (n−1) = n(n−1)/2
~~~

Поэтому:
~~~text
xₙ = [n(n−1)/2] / n² = (n−1)/(2n)
     = 1/2 − 1/(2n)
~~~

Так как 1/(2n) → 0:
~~~text
limₙ→∞ xₙ = 1/2
~~~

В этом примере сумма в числителе похожа на арифметическую прогрессию; её сначала сворачивают по формуле суммы, а затем упрощают дробь.

## 6. Исследование последовательности (2n + 1)/(2n + 3)

Рассмотрим:
~~~text
xₙ = (2n + 1)/(2n + 3),   n = 1, 2, 3, …
~~~

Первые пять членов:
~~~text
x₁ = 3/5
x₂ = 5/7
x₃ = 7/9
x₄ = 9/11
x₅ = 11/13
~~~

### Монотонность

Сравним соседние члены:
~~~text
xₙ₊₁ − xₙ
= (2n + 3)/(2n + 5) − (2n + 1)/(2n + 3)
= 4/[(2n + 5)(2n + 3)] > 0
~~~

Значит, последовательность строго возрастает.

### Ограниченность

Для всех n ≥ 1:
~~~text
0 < (2n + 1)/(2n + 3) < 1
~~~

Первый член равен 3/5, а все последующие больше него и меньше 1:
~~~text
3/5 ≤ xₙ < 1
~~~

Последовательность ограничена снизу и сверху.

### Предел

Разделим числитель и знаменатель на n:
~~~text
xₙ = (2 + 1/n)/(2 + 3/n) → 2/2 = 1
~~~

Итак, последовательность возрастает, ограничена и сходится к 1.

В распознанной записи при обсуждении первого члена прозвучало также 1/3. Это сдвиг индекса: для общего члена (2n+1)/(2n+3) при n=1 получается 3/5. Если индексировать ту же последовательность с нуля, первый член будет 1/3; формулу и начало нумерации нужно согласовывать.

### Переход от явной формулы к рекуррентной

Рекуррентное задание выражает xₙ₊₁ через xₙ. Для этой последовательности:
~~~text
xₙ₊₁ = (2n + 3)/(2n + 5) = 1/(2 − xₙ)
~~~

При нумерации n = 1, 2, … начальное значение x₁ = 3/5, поэтому:
~~~text
x₁ = 3/5
xₙ₊₁ = 1/(2 − xₙ)
~~~

В лекции рекуррентную формулу восстанавливали через решение явного выражения относительно n и подстановку найденного выражения в формулу для следующего члена.

## 7. Короткий порядок исследования последовательности

Для заданной формулой последовательности удобно:

1. Найти несколько первых членов, подставив n = 1, 2, 3, …
2. Предположить, возрастает она или убывает.
3. Проверить гипотезу в общем виде через разность xₙ₊₁ − xₙ.
4. Проверить ограниченность — найти числа, между которыми лежат все члены.
5. Найти предел, если он существует.
6. Если последовательность колеблется, проверить подходящие подпоследовательности.

Первые несколько членов помогают заметить закономерность, но сами по себе не доказывают её для всех n. Для доказательства используют общий член последовательности.

## Главное

- Предел задаётся условием: после некоторого номера все члены находятся на расстоянии меньше ε от числа a.
- Монотонность не является необходимым условием сходимости.
- Последовательность с конечным пределом сходится; бесконечно малая последовательность имеет предел 0.
- Ограниченная последовательность может расходиться, но из неё можно выделить сходящуюся подпоследовательность.
- Разные пределы двух подпоследовательностей доказывают расходимость исходной последовательности.
- Для рациональных выражений от n часто помогает деление числителя и знаменателя на наибольшую степень n.
- При переходе к рекуррентной записи нужно указывать начальный член и согласованную нумерацию.
