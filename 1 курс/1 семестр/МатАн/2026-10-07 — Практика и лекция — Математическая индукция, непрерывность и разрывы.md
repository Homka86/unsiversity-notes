## 1. Метод математической индукции

Математическая индукция позволяет доказать утверждение для всех натуральных номеров. Идея похожа на цепочку домино: нужно проверить первый элемент и показать, что истинность для одного номера влечёт истинность для следующего.

### Три шага доказательства

Пусть требуется доказать утверждение P(n) для всех n ≥ 1.

1. **База индукции.** Проверить, что P(1) верно.
2. **Индуктивное предположение.** Предположить, что P(k) верно для произвольного фиксированного k.
3. **Индуктивный переход.** Используя предположение P(k), доказать P(k + 1).

Только после этих шагов можно заключить, что утверждение верно для всех натуральных n. В переходе важно пользоваться предположением именно для k, а не считать утверждение для k + 1 уже доказанным.

### Пример: сумма квадратов первых натуральных чисел

Доказывается формула:

~~~text
1² + 2² + … + n² = n(n + 1)(2n + 1) / 6.
~~~

**База:** при n = 1 обе части равны 1.

**Предположение:** для некоторого k ≥ 1 верно:

~~~text
1² + 2² + … + k² = k(k + 1)(2k + 1) / 6.
~~~

**Переход:** прибавляем к обеим частям следующий квадрат:

~~~text
1² + … + k² + (k + 1)²
= k(k + 1)(2k + 1) / 6 + (k + 1)²
= (k + 1)(k + 2)(2k + 3) / 6.
~~~

Получили ту же формулу с заменой n на k + 1, поэтому переход доказан.

## 2. Рекуррентное и явное задание последовательности

Последовательность может быть задана через предыдущий член — рекуррентно. В примере на занятии:

~~~text
x₁ = 1,
xₙ₊₁ = xₙ / (1 + xₙ).
~~~

Первые члены:

~~~text
x₁ = 1,  x₂ = 1/2,  x₃ = 1/3,  x₄ = 1/4, …
~~~

По первым значениям можно предположить явную формулу xₙ = 1/n, но наблюдение нескольких членов само по себе не доказывает формулу для всех n.

### Доказательство формулы xₙ = 1/n индукцией

- **База:** x₁ = 1 = 1/1.
- **Предположение:** пусть xₖ = 1/k.
- **Переход:** подставляем в рекуррентное правило:

~~~text
xₖ₊₁ = (1/k) / (1 + 1/k) = (1/k) / ((k + 1)/k) = 1/(k + 1).
~~~

Значит, формула верна для всех n ≥ 1.

В записи показали два равносильных способа перехода: подставить предполагаемую явную формулу в рекуррентное правило либо выразить k через xₖ и подставить это выражение в формулу для следующего члена.

Последовательности рассматриваются как функции дискретного аргумента: их номера принимают натуральные значения. Это подготавливает переход к пределам функций.

## 3. Непрерывность функции в точке

Функция f непрерывна в точке x₀, если выполнены три условия:

1. функция определена в самой точке x₀ и в некоторой её окрестности;
2. существует конечный предел lim(x→x₀) f(x);
3. этот предел равен значению функции: lim(x→x₀) f(x) = f(x₀).

Непрерывность проверяют в конкретной точке. Для непрерывности на множестве условие должно выполняться в каждой его внутренней точке; на концах отрезка рассматривают одностороннюю непрерывность изнутри отрезка.

### Непрерывность и предел сложной функции

Если g непрерывна в точке a, а u(x) → a, то при допустимости композиции можно перейти к пределу внутри непрерывной функции:

~~~text
lim g(u(x)) = g(lim u(x)) = g(a).
~~~

Пример из занятия:

~~~text
lim(x→0) e^(sin(x)/x) = e^1 = e,
~~~

поскольку первый замечательный предел даёт lim(x→0) sin(x)/x = 1, а экспонента непрерывна.

В дальнейшем можно пользоваться тем, что основные элементарные функции непрерывны во всех точках своей области определения. Сумма и произведение непрерывных функций также непрерывны; частное — при ненулевом знаменателе. Композиция непрерывных функций непрерывна.

## 4. Приращения и второе описание непрерывности

При фиксированной точке x₀ приращение аргумента и соответствующее приращение функции обозначают так:

~~~text
Δx = x − x₀,
Δy = f(x) − f(x₀).
~~~

Приращения могут быть положительными или отрицательными: знак показывает направление изменения. Если x → x₀, то Δx → 0. Непрерывность в точке можно выразить равносильным условием:

~~~text
lim(Δx→0) Δy = 0.
~~~

Иными словами, бесконечно малому приращению аргумента соответствует бесконечно малое приращение функции. Эта запись пригодится при изучении производной; определение через предел и значение функции удобно при исследовании функций.

## 5. Точки разрыва и их классификация

Точка, в которой нарушено хотя бы одно из условий непрерывности, называется **точкой разрыва**.

### Устранимый разрыв

В точке x₀ существует конечный общий предел слева и справа, но значение функции отсутствует или не равно этому пределу. Если функция не определена в точке, её можно доопределить значением этого предела и устранить разрыв.

Пример: f(x) = cos x при x ≠ 0, а f(0) = 2. Предел при x → 0 равен 1, но f(0) = 2; разрыв устранимый.

### Разрыв первого рода (скачок)

Конечные односторонние пределы существуют, но не равны:

~~~text
lim(x→x₀−) f(x) = A,
lim(x→x₀+) f(x) = B,
A ≠ B.
~~~

В примере с точкой x₀ = 2 слева функция стремится к 1, справа — к 0. Предела в точке нет; величина скачка равна |A − B|.

Обозначения x₀−0 и x₀+0 указывают на приближение к точке слева и справа соответственно.

### Разрыв второго рода

Хотя бы один из односторонних пределов не существует или бесконечен. Например, при x → 0 функция sin(1/x) не имеет предела: её значения колеблются и не приближаются к одному числу. Сюда же относятся случаи, когда функция уходит в бесконечность.

## 6. Непрерывность на интервале и отрезке

- На **интервале** функция непрерывна, если она непрерывна в каждой точке интервала.
- На **отрезке [a, b]** дополнительно требуется непрерывность справа в a и слева в b: значения функции рассматриваются со стороны самого отрезка.

Для внутренних точек проверяют обычную двустороннюю непрерывность.

## 7. Теоремы о непрерывных функциях

Теоремы на занятии не доказывали; их нужно будет применять.

### Теорема Вейерштрасса о достижении экстремумов

Если функция непрерывна на отрезке [a, b], то она достигает на нём наибольшего и наименьшего значений.

### Теорема о промежуточных значениях

Если функция непрерывна на [a, b], то она принимает все значения между f(a) и f(b).

**Следствие о корне:** если f непрерывна на [a, b] и f(a) и f(b) имеют разные знаки, то внутри отрезка найдётся точка c, для которой f(c) = 0.
