## 1. Обозначения и виды систем

Систему из n линейных уравнений с n неизвестными можно записать в матричном виде:

~~~text
A X = B,
~~~

где:

- A — матрица коэффициентов системы;
- X — столбец неизвестных;
- B — столбец свободных членов;
- Δ = det A — определитель матрицы коэффициентов.

Система называется:

- **невырожденной**, если Δ ≠ 0;
- **вырожденной**, если Δ = 0;
- **совместной**, если имеет хотя бы одно решение;
- **несовместной**, если решений нет;
- **определённой**, если имеет единственное решение;
- **неопределённой**, если имеет бесконечно много решений.

Если Δ ≠ 0, матрица A обратима и система имеет единственное решение. Если Δ = 0, теорема Крамера неприменима: система может не иметь решений или иметь бесконечно много решений.

## 2. Теорема Крамера

Теорема применяется, когда система квадратная — число уравнений равно числу неизвестных — и определитель матрицы коэффициентов ненулевой.

Для каждого неизвестного xᵢ вычисляют вспомогательный определитель Δᵢ: в матрице A заменяют i-й столбец столбцом свободных членов B. Тогда

~~~text
xᵢ = Δᵢ / Δ,  где Δ ≠ 0.
~~~

То есть:

~~~text
x₁ = Δ₁ / Δ,  x₂ = Δ₂ / Δ,  …,  xₙ = Δₙ / Δ.
~~~

### Почему работает формула Крамера

Так как Δ ≠ 0, существует обратная матрица:

~~~text
A⁻¹ = (1 / Δ) · adj(A),
~~~

где adj(A) — присоединённая матрица, то есть транспонированная матрица алгебраических дополнений.

Из A X = B умножаем **слева** на A⁻¹:

~~~text
X = A⁻¹ B = (1 / Δ) · adj(A) B.
~~~

Каждая координата получившегося столбца — сумма элементов столбца B, умноженных на соответствующие алгебраические дополнения. По теореме о разложении определителя эта сумма равна определителю матрицы A, в которой соответствующий столбец заменён на B. Это и есть Δᵢ. Поэтому xᵢ = Δᵢ / Δ.

## 3. Пример решения по Крамеру

В разобранном на занятии примере для системы из трёх уравнений получили:

~~~text
Δ = 12,
Δ₁ = 24,
Δ₂ = −24,
Δ₃ = 36.
~~~

Следовательно:

~~~text
x = Δ₁ / Δ = 2,
y = Δ₂ / Δ = −2,
z = Δ₃ / Δ = 3.
~~~

Главная часть вычислений — аккуратно составить вспомогательные определители: каждый раз заменить **только столбец соответствующей неизвестной**, остальные столбцы оставить такими, как в A.

## 4. Как упрощать определители

Перед вычислением полезно посмотреть, можно ли получить в строке или столбце нули, а затем применить разложение по ним.

### Операции, которые использовали на занятии

- К одной строке прибавить другую строку, умноженную на число:  
  **определитель не меняется**. Аналогичное правило действует для столбцов.
- Если все элементы одной строки или столбца имеют общий множитель, его можно вынести за знак определителя.
- Перестановка двух строк или двух столбцов меняет знак определителя.
- Если в строке или столбце получились нули, удобно разложить определитель по этой строке или столбцу.
- Определитель треугольной матрицы равен произведению элементов главной диагонали.
- Если две строки (или два столбца) совпадают либо пропорциональны, определитель равен нулю.

Практический приём: выбрать удобный элемент — часто 1 или −1 — и прибавлением кратной строки/столбца занулить остальные элементы в его строке или столбце. Затем либо разложить определитель, либо привести его к треугольному виду.

При вынесении множителя следите за знаком: например, если из строки выносится −1, перед определителем появляется множитель −1.

## 5. Решение системы через обратную матрицу

Для системы

~~~text
A X = B
~~~

если det A ≠ 0, умножаем обе части **слева** на A⁻¹:

~~~text
A⁻¹ A X = A⁻¹ B,
X = A⁻¹ B.
~~~

Обратная матрица находится по формуле:

~~~text
A⁻¹ = (1 / det A) · adj(A)
    = (1 / det A) · (A*)ᵀ,
~~~

где A* — матрица алгебраических дополнений, а верхний индекс T означает транспонирование.

Для нахождения алгебраического дополнения элемента aᵢⱼ используют знак:

~~~text
Aᵢⱼ = (−1)^(i+j) · Mᵢⱼ,
~~~

где Mᵢⱼ — минор, полученный вычёркиванием i-й строки и j-го столбца. Знаки удобно заранее записать шахматно:

~~~text
+  −  +  …
−  +  −  …
+  −  +  …
…
~~~

После вычисления матрицы алгебраических дополнений её обязательно транспонируют. Затем умножают на 1/det A.

### Что важно при матричном умножении

Порядок множителей менять нельзя: умножение матриц в общем случае некоммутативно. Если исходное уравнение A X = B, умножаем на обратную матрицу слева и получаем A⁻¹B. Нельзя без основания переставить A⁻¹ и B.

Множитель 1/det A удобно оставить перед матричным произведением до конца, чтобы не получать дроби в каждом элементе. Результат можно проверить подстановкой: A X должен равняться B.

## 6. Матричное уравнение с неизвестной матрицей

Рассмотрели уравнение вида:

~~~text
A X B = C.
~~~

Чтобы изолировать X:

1. избавиться от A слева — умножить обе части слева на A⁻¹;
2. избавиться от B справа — умножить обе части справа на B⁻¹.

Получается:

~~~text
A⁻¹ (A X B) B⁻¹ = A⁻¹ C B⁻¹,
X = A⁻¹ C B⁻¹.
~~~

Обе обратные матрицы должны существовать. Порядок множителей сохраняется: сначала A⁻¹ слева, затем B⁻¹ справа. Числовые множители, например 1/det A и 1/det B, можно объединить и вынести перед произведением, но матрицы переставлять нельзя.

Перед перемножением проверяйте размеры матриц. В демонстрации преподаватель последовательно умножала матрицы размера 2×2, 2×3 и 3×3; итоговая матрица X должна иметь такие размеры, чтобы исходное равенство A X B = C было определено.

## 7. Если определитель равен нулю

Условие Δ = 0 означает, что метод Крамера и формула обратной матрицы для исходной матрицы A не работают. Но это **не означает автоматически**, что решений нет.

Нужно исследовать уравнения. Если одна строка коэффициентов пропорциональна другой, соответствующее уравнение может оказаться повторением. Его можно убрать, если свободные члены согласованы. После этого в системе может остаться меньше независимых уравнений, чем неизвестных. Тогда одну из неизвестных задают свободным параметром и выражают остальные через неё.

Если после исключения зависимых уравнений остаётся противоречие, решений нет. Для общего исследования вырожденных и прямоугольных систем на лекции обещали метод Гаусса — универсальный способ, который можно применять и тогда, когда теорема Крамера неприменима.

## 8. Как выбирать метод

- Если прямо указано **«решить методом Крамера»**, сначала проверяют, что система квадратная и Δ ≠ 0, затем вычисляют Δ и вспомогательные Δᵢ.
- Если указан **метод обратной матрицы**, проверяют det A ≠ 0, находят A⁻¹ и вычисляют X = A⁻¹B.
- Если способ не указан, можно выбрать любой применимый метод.
- Методы Крамера и обратной матрицы имеют одинаковое условие применимости к системе: она квадратная и невырожденная. На контрольной работе метод могут указать специально, чтобы проверить владение именно им.
- Если det A = 0 или система не квадратная, используют другой метод, в частности метод Гаусса.
